# Mi Ruta de Aprendizaje en Programación - Capacitar 🚀

¡Hola! Bienvenido a mi repositorio de prácticas. En este espacio voy a ir subiendo todos los ejercicios, desafíos y códigos que desarrolle durante la **Ruta de Aprendizaje de Lenguajes de Programación** dictada por el programa Capacitar de Argentina.gob.ar.

## 📌 Objetivos de este Repositorio
* **Aprender las bases:** Registrar mi progreso en lógica de programación, estructuras de datos y algoritmos.
* **Demostrar autoría:** Dejar constancia de mi proceso de aprendizaje subiendo el código paso a paso y de forma constante.
* **Crear Portfolio:** Construir la base técnica necesaria para certificarme internacionalmente y postularme a mis primeros roles en tecnología.

## 📂 Organización del Proyecto
El código está ordenado cronológicamente por temas en carpetas individuales para facilitar su lectura.

## 🛠️ Herramientas Utilizadas
* **Lenguaje:** Entornos de práctica del curso (Python / JavaScript).
* **Editor de Código:** Visual Studio Code.
* **Control de Versiones:** Git y GitHub.

---
*Este repositorio no cuenta con certificación oficial emitida por el programa, por lo que todo el código aquí presentado sirve como evidencia real y verificable de mis conocimientos técnicos.*
